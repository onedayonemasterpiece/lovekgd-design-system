# LoveKGD Design System

Канонический репозиторий дизайн-системы зонтичного бренда «Полюбить Калининград» и его продуктовых расширений.

Сейчас репозиторий инициализируется с изолированного прототипа Penpot review-plugin. Прототип проверяет только один пользовательский цикл: артефакт берётся из Git, комментарий читается штатным Plugin API, а промпт собирается по шаблону из того же Git.

См. [`prototypes/penpot-review-plugin/README.md`](prototypes/penpot-review-plugin/README.md).
