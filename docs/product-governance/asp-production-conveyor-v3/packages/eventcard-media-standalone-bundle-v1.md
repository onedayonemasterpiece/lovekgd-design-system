# EventCard Media standalone bundle v1

Package-local successor for `MAT-EVENTCARD-MEDIA-SAME-TUPLE-EXECUTION-R3`.
It exposes `globalThis.KenigEventsD0EventcardMediaR3StandaloneV3` as one browser/Penpot-safe JavaScript artifact with fresh four-target projection, four in-place fill execution and distinct coverage settlement entrypoints. The exact two WebP inputs and a portable SHA-256 implementation are embedded; no repository loader, Node built-ins or publisher-side source copying is required. Exact bundle bytes and SHA-256 are repeated in the authorization and provenance tuple. Penpot execution remains independent QA/INTEGRATE, fresh-projection and bounded ACTIVE gated; Text is unchanged and remains blocked.

The V3 global uses a deterministic plain-data clone for projection values and never invokes the Penpot sandbox `structuredClone` host function.

V3 closes the caller-helper gap: the artifact owns `readNativeCoverage`, hashes each native fill `ImageData.data()` payload, evaluates exact fill/shape aspect coverage and parent z-order opaque overlap before execution and again at settlement. No caller-injected coverage function is accepted or required. Every `uploadMediaData()` result must expose callable `ImageData.data()` and match exact source bytes/SHA-256 before the first fill setter; failure stops as unknown outcome with a distinct read-only projection and no blind retry.

V3 reads the physical ACTIVE marker directly from `currentFile.getSharedPluginData`; production entrypoints require no caller function for time, marker, source bytes, settlement, projection, or coverage. Tests invoke the exact bundle with a data-only context plus the actual Penpot API surface.
