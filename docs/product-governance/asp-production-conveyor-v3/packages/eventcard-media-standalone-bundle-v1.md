# EventCard Media standalone bundle v1

Package-local successor for `MAT-EVENTCARD-MEDIA-SAME-TUPLE-EXECUTION-R3`.
It exposes `globalThis.KenigEventsD0EventcardMediaR3StandaloneV5` as one browser/Penpot-safe JavaScript artifact with the real production projection, phased in-place fill execution and distinct coverage settlement entrypoints. The exact two WebP inputs plus package-owned UTF-8/SHA-256 primitives are embedded. The generated artifact has no repository loader, Node built-ins, `structuredClone`, Web Crypto dependency, caller-injected helper, or conformance-only dispatch.

V5 reads only `currentFile.revn` and the sole physical marker `currentFile.getSharedPluginData('kenigevents', 'asp-active-run-v1')`. Authorization, provenance and `kenigevents.asp-run-control.v1` must carry the exact provider head/tree, bundle SHA/bytes, revision, initial projection SHA, session/task/trigger/cancel/lease tuple, current D0 shift marker `5514360206`, Media-only authority scope, and sole writer `/root/publish_r2`. The old blocked Text page profile is not an authority input for Media.

Execution is resumable and bounded to one native `uploadMediaData()` create per invocation (therefore no more than three). Before each target it persists `UNKNOWN_PENDING_DISTINCT_READBACK`; after exact uploaded `ImageData.data()` verification, in-place fill replacement, four string-only evidence writes and readback it advances a durable cursor to `PARTIAL_CONFIRMED` or `DONE`. A durable UNKNOWN state rejects generic retry without another upload. The terminal receipt binds the full package/bundle/revision/projection/authority tuple and all four root, media and parent IDs; settlement exact-compares that stored receipt and performs a distinct four-target byte, coverage and z-order readback.

The conformance fixture seeds a native-like four-target page, 18 collection children and 35 local components without setup creates, then drives the same public production entrypoints through four phases. It is fixture plumbing only: the bundle contains no conformance authorization bypass.

This package is QA/INTEGRATE gated. It performs no Penpot read or mutation from U0, does not authorize promotion, and leaves Text and every non-Media surface unchanged.
