# G12 current-A batched Penpot executor

This immutable candidate is not a Penpot run authorization. It binds exact browser-used
Astro evidence from `w2-free-collection-visual-evidence-g12` and packages one governed
EventCard component identity with four structural variants.

W3 must first run `catalog/penpot-executor/g12/penpot-empty-baseline-probe.js` read-only.
W0 validates that observation and separately authorizes a reversible
`createShapeFromSvgWithImages` canary. Only after the canary passes may W0 issue the next
short-lived batch capsule. W3 calls `executeBatch` once, returns its checkpoint receipt,
and waits for W0 to fresh-read generation, cancellation, and lease state before W0 issues
another batch. Prefix attestations are integrity labels, not cryptographic signatures.

The executor performs no filesystem or network access. The run-specific file/page IDs,
generation, run ID, tickets, and cancellation state exist only in future W0-issued
capsules and receipts. No Penpot mutation was performed while producing this candidate.
