- explicitly resolves a real Penpot font object (Inter or an explicit sans fallback);
- safely organizes legacy Runtime Review 003.2 boards into evidence pages;
- deletes only empty legacy pages, preserving comment-bearing evidence/archive pages;
- creates native product component masters;
- composes product-pattern masters from component instances;
- builds every required page archetype from linked instances;
- links archetypes to available runtime evidence;
- creates fragmentation clusters and `75 — Design gaps`;
- stores an in-file unresolved-comment registry for later external persistence.
